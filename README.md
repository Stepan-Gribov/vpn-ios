# VPNApp для iOS

TnDtun для iPhone и iPad. Приложение на SwiftUI управляет VPN-профилями и подписками, импортирует конфигурации и использует расширение Network Extension для подключения. Оно поддерживает раздельную маршрутизацию, статистику трафика и восстановление соединения.

- [App](App) — интерфейс, настройки, импорт и резервное копирование.
- [Core](Core) и [Shared](Shared) — профили, модель подключения, настройки и обмен данными с расширением.
- [PacketTunnel](PacketTunnel) — жизненный цикл VPN и взаимодействие с сетевым движком.
- [Packages/SwiftyXrayKit](Packages/SwiftyXrayKit) — Swift-обёртки для сетевого движка.
- [Tests](Tests) и [UITests](UITests) — проверки конфигураций, маршрутизации и интерфейса.

## Сборка

Понадобятся Xcode со Swift 6 и XcodeGen. Проект рассчитан на iOS 16 и новее.

1. Укажите свои идентификаторы приложения, расширения, группы приложений и команду подписи в [project.yml](project.yml).
2. Добавьте совместимый `LibXray.xcframework` в `Packages/SwiftyXrayKit/Frameworks/`. Он должен предоставлять интерфейсы, которые использует Swift-пакет. Для профильных правил со списками стран или доменов можно также добавить `Resources/geoip.dat` и `Resources/geosite.dat`.
3. Выполните `xcodegen generate`, откройте `TnDtun.xcodeproj` и выберите схему **TnDtun**. Для проверки сетевого туннеля нужен подписанный билд на устройстве.

Текущая версия 1.0 (50). Сетевой бинарник, настройки серверов и материалы подписи нужны отдельно. Для функций собственной панели можно добавить локальный `Resources/panel-bootstrap.json` и задать `VPNAPP_RECOVERY_URL` в настройках проекта.

## Обновление подписок

Панель может включить обновление через `settings.subscriptionSync` в подписанном пакете. Поле принимает `enabled` (логическое значение) и `intervalMinutes` (целое от 15 до 1440). Приложение применяет политику после проверки и сохранения пакета. Без поля или с `enabled: false` доступно ручное обновление.

У каждой подписки свой срок обновления. Приложение проверяет просроченные подписки при открытии и пока оно активно. В фоне интервал задаёт самое раннее время запуска `BGAppRefreshTask`. Точный момент выбирает iOS. После ошибки автоматическая попытка откладывается на 15 минут. Под **Refresh** отображается местное время последнего успешного обновления среди сохранённых подписок.
