# VPNApp для iOS

TnDtun для iPhone и iPad. Приложение на SwiftUI управляет VPN-профилями и подписками, импортирует конфигурации и использует расширение Network Extension для подключения. В сборке 47 также есть раздельная маршрутизация, статистика трафика и восстановление соединения.

- [App](App) — интерфейс, настройки, импорт и резервное копирование.
- [Core](Core) и [Shared](Shared) — профили, модель подключения, настройки и обмен данными с расширением.
- [PacketTunnel](PacketTunnel) — жизненный цикл VPN и взаимодействие с сетевым движком.
- [Packages/SwiftyXrayKit](Packages/SwiftyXrayKit) — Swift-обёртки для сетевого движка.
- [Tests](Tests) и [UITests](UITests) — проверки конфигураций, маршрутизации и интерфейса.

## Сборка

Понадобятся Xcode со Swift 6 и XcodeGen. Проект рассчитан на iOS 16 и новее.

1. Укажите свои идентификаторы приложения, расширения, группы приложений и команду подписи в [project.yml](project.yml).
2. Добавьте совместимый `LibXray.xcframework` в `Packages/SwiftyXrayKit/Frameworks/`. Он должен предоставлять интерфейсы, которые использует Swift-пакет. Для профильных правил со списками стран или доменов можно также добавить `Resources/geoip.dat` и `Resources/geosite.dat`.
3. Выполните `xcodegen generate`, откройте `TnDtun.xcodeproj` и выберите схему **TnDtun**. Для проверки сетевого туннеля нужен подписанный билд на устройстве.

Базовый снимок — версия 1.0, сборка 47. Сетевой бинарник, настройки серверов и материалы подписи нужны отдельно. Для функций собственной панели можно добавить локальный `Resources/panel-bootstrap.json` и задать `VPNAPP_RECOVERY_URL` в настройках проекта. Проверка запроса доступа выполняется вручную в приложении.
